\textbf{AST} & Abstract Syntax Tree: the structured representation produced after Litho parses a document. \\
\textbf{CommonMark} & The baseline Markdown specification on which the Litho dialect is based. \\
\textbf{Dialect} & The project-defined Markdown extension that adds document and template constructs while retaining familiar Markdown authoring. \\
\textbf{MCP} & Model Context Protocol: an interface through which AI assistants can invoke document tooling and access template context. \\
\textbf{Template manifest} & A JSON document that declares a template's identity, version, supported fields, schema, assets, and authoring constraints. \\
\textbf{Template package} & The distributable unit containing a declarative schema, JSON manifest, assets, documentation, and semantic version metadata. \\
\textbf{Tectonic} & The self-contained \TeX\ engine used by the build pipeline to compile generated \LaTeX\ into PDF. \\
\textbf{Round-trip restoration} & The operation of recovering the original Markdown source and associated template information from a generated document. \\
