\chapter{Template Manifest and Package Specification}
\label{app:template-manifest}

This appendix defines the minimum structure of a publishable Litho template
package. The package is declarative: template authors describe supported fields,
assets, and rendering constraints without adding arbitrary interpreter code. The
manifest is validated by the publisher tooling before a package is submitted for
review, as required by FR-13--FR-15 and DIR-01.

\section{Validation and Publication Rules}
\begin{enumerate}
  \item The manifest must be valid JSON and contain every required field.
  \item The package identifier and semantic version must be unique for the selected
  release.
  \item Every schema field referenced by the template must be declared in the
  manifest, and every referenced asset must exist inside the package.
  \item Template resources must use only the approved declarative constructs and
  package dependencies; arbitrary macro execution is not permitted.
  \item The CLI must report validation errors before submission. A package may be
  submitted to the marketplace only after schema, asset, compatibility, and
  licensing checks pass.
\end{enumerate}
